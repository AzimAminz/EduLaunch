# @edulaunch/web

Next.js 16 website for students and admins. See the [setup guide](../../docs/setup.md) to set up and run the whole system.

- `pnpm --filter @edulaunch/web dev` runs only this app on http://localhost:3000.
- Calls to `/api/*` are forwarded to the gateway (`GATEWAY_URL`, default http://127.0.0.1:4000); see `next.config.ts`.
- Sign-in uses Supabase from the browser: `lib/supabase/client.ts`. Only the publishable key is used here.
- Environment values live in `.env.local`, generated by `pnpm env:setup`.
- Next.js 16 differs from older versions; read `node_modules/next/dist/docs/` before using an unfamiliar API (see `AGENTS.md`).
